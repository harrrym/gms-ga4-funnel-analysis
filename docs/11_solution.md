# 11. 해결 가설

본 해결 가설과 실험 설계는 데이터 분석 직후 시점을 가정하고 작성했다.

## 원인 요약

12월 중순 이후 구매전환율(OMTM)이 크게 떨어졌고(1.895% → 0.748%, −60.5%), 하락의 약 76%는 방문→담기 단계에서 나왔다([docs/09](09_problem_redefinition.md)). 원인 분석 결과, 배송 마감(12/18) 이후 선물을 살 이유가 사라져 목록까지 와도 담지 않았고, 특히 선물 성격이 강한 의류에서 크게 줄었다는 설명이 남았다. 다만 이 설명은 다른 가설을 배제하고 남은 것이며 직접 검증한 것은 아니다. 자세한 판정과 근거는 [docs/10 결론](10_root_cause.md#결론)에 있다.

## A. 원인에 대한 해결 (시즌 하락)

### A1. 마감 이후 기프트카드 노출

| 항목 | 내용 |
|---|---|
| 가설 | 배송 마감 이후 목록 페이지를 보는 사용자에게 이미 있던 기프트카드를 노출하면, 이 기간의 구매전환율이 오를 것이다. |
| 근거 | 하락이 배송 마감 직후 시작됐다([docs/10 결론 근거 1](10_root_cause.md#근거), [docs/09 2절](09_problem_redefinition.md#2-omtm-하락구간)). 사이즈 있는 의류의 하락폭이 더 크다(Hats 제외 −44% vs 사이즈 없는 상품 −19%, [docs/10 H2 보완](10_root_cause.md#h2-보완-사이즈-품절과-품절-직접-확인-판정-보류)). 의류는 배송 시점과 사이즈를 모두 맞춰야 해서 마감 이후에는 선물로 사기 어렵다는 것은 해석이다. 기프트카드는 받는 사람이 사이즈와 상품을 직접 고를 수 있어 사이즈 품절 문제도 피할 수 있다. 다만 당시 스토어에 기프트카드($10~$250)가 이미 있었다(`sql/237`). 전자 발송 여부는 데이터로 확인할 수 없다(11/23 이후 기프트카드 주문 11건 모두 배송 등급이 비어 있어 배송 방법을 고르지 않는 상품이었을 가능성은 있다, `sql/238`). |
| 주 지표 | 마감 이후 기간 구매전환율 |
| 함께 볼 지표 | 기프트카드 매출, 일반 상품 구매 비중(기프트카드가 일반 구매를 대체했는지), 구매 세션당 매출 |
| 위험 | 기존 상품 구매를 기프트카드가 대체할 수 있음. 선물 대상에 따라 기프트카드 선호가 다를 수 있으나 이용자 특성 데이터가 없어 확인할 수 없음. 배송 마감 이후 기프트카드 페이지 방문 비율이 오히려 줄었다(목록 방문자 대비 0.25% → 0.07%, 숫자가 작아 방향만 확인 가능, `sql/240`, `sql/242`). 배송 장벽이 아니라 선물 의도 자체가 줄었다면 기프트카드 노출 효과는 제한적일 수 있음 |
| 실험 시기 | 다음 연말 배송 마감 이후. 연말 외 배송 마감이 있는 다른 선물 시즌(발렌타인데이, 어머니날 등)에서도 방향을 먼저 확인할 수 있음 |

### A2. 마감 이후 주문 즉시 할인

| 항목 | 내용 |
|---|---|
| 가설 | 배송 마감 이후 주문에 즉시 할인을 제공하면, 이 기간의 구매전환율이 오를 것이다. |
| 근거 | 하락이 배송 마감 직후 시작됐다([docs/10 결론 근거 1](10_root_cause.md#근거)). 마감 이후 "제때 못 받는" 단점을 가격으로 보상해 새로운 살 이유를 만든다는 것은 해석이다. |
| 주 지표 | 마감 이후 기간 구매전환율 |
| 함께 볼 지표 | 구매 세션당 매출, 할인 사용률, 할인 반영 후 매출(마진 영향), 할인으로 유입된 사용자의 재구매율 |
| 위험 | 마진 감소, 반복하면 사용자가 마감 이후 할인을 기다리게 됨 |
| 실험 시기 | 다음 연말 배송 마감 이후 |

### A3. 구경 이탈 리마인드

| 항목 | 내용 |
|---|---|
| 가설 | 목록을 보고 장바구니에 담지 않고 떠난 사용자에게 리타게팅 광고를 보여주면, 7일 안 재방문율이 15.9%에서 17.5%(상대 +10%) 이상으로 오를 것이다. 배송 마감 이후 이탈자에게 1월 중순(1/12부터) 보내는 시점 비교는 후속 실험이다(docs/12). |
| 근거 | 하락구간 이탈자는 스스로 돌아와 담는 비율이 크게 낮았다([docs/10 H1b](10_root_cause.md#h1b-마감-후-구매-유예-기각), 목록을 보고 담지 않은 사용자의 7일 추적, 기준선 → 하락구간 → 회복기). 이 비율은 두 단계로 나뉜다. **7일 안 재방문율** 19.8% → 12.9% → 15.9%, **재방문한 사용자 중 장바구니에 담은 비율** 11.7% → 6.6% → 9.4%(`data/216`으로 다시 계산해 확인, 회복기는 7일 추적이 가능한 1/12~1/24 세션). 둘을 곱한 7일 안 재방문 후 장바구니 담기 비율은 2.31% → 0.86% → 1.51%다. 하락구간엔 두 비율이 모두 떨어졌고, 리마인드는 돌아오게 하는 7일 안 재방문율만 해결한다. 돌아와서 담는 비율은 리마인드로 바뀌지 않으므로, 마감 이후 이탈자에게는 재방문한 사용자 중 장바구니에 담은 비율이 회복되는 시기(회복기 1/12~)에 보낸다. |
| 주 지표 | 7일 안 재방문율 |
| 함께 볼 지표 | 2차 지표: 7일 안 재방문 후 장바구니 담기 비율. 가드레일: 재방문한 사용자 중 장바구니에 담은 비율, 장바구니에 담은 사용자의 구매율, 광고비 대비 매출. 모니터링: 7일 안 구매율, 광고 노출 빈도 |
| 위험 | 광고 비용이 들고, 광고 차단·쿠키 삭제·여러 기기 사용으로 도달이 제한됨. 과도한 노출은 피로감을 줄 수 있음 |
| 실험 시기 | 기능은 상시, 시즌 타이밍 효과는 다음 연말 |

## B. 분석 중 발견한 문제 개선 (상시)

### B1. 품절 상품 재입고 알림·비슷한 상품 추천

하락 원인과는 별개로 분석 중 발견한 문제다. docs/10에서 품절은 하락의 주원인이 아니었다(H2 보류, 일부 상품에 한정).

| 항목 | 내용 |
|---|---|
| 가설 | 목록 페이지에서 품절 상품의 담기 버튼 대신 재입고 알림과 비슷한 상품 추천을 보여주면, 최종 구매전환율이 오를 것이다. |
| 근거 | 품절인데도 담기 버튼이 활성화되어 있었다(11/28 웹 아카이브, Google Leather Strap Hat Black이 "Out of Stock"인데 "ADD TO CART" 활성). 그래서 품절 상품에 담기만 쌓이고 구매는 거의 없었다(Eco Tee Black 기준선 담기 483건 vs 구매 10개, 기준선 Hats 목록 세션의 결제시작→구매 27.6%로 그 외 세션 55.4%의 약 절반). 재고 관련 배너도 있었다(12/3 재입고 안내, 1/22 재고 추가 중). 자세한 내용은 [docs/10 H2 보완](10_root_cause.md#h2-보완-사이즈-품절과-품절-직접-확인-판정-보류), [Hats 효과](10_root_cause.md#hats-효과). |
| 주 지표 | 구매전환율 |
| 함께 볼 지표 | 비슷한 상품 장바구니 담기 비율, 재입고 알림 신청 수 |
| 위험 | 비슷한 상품 추천이 맞지 않으면 그대로 이탈할 수 있음, 재입고 알림 후 실제 재입고가 늦으면 불만이 생길 수 있음, 재고 데이터와 연동하는 개발 비용 |
| 예상되는 변화 | 품절 상품 담기는 줄어듦(의도한 결과) |
| 실험 시기 | 언제든 |

### B2. 목록 카드 별점·리뷰 수

| 항목 | 내용 |
|---|---|
| 가설 | 목록 페이지를 보는 사용자, 특히 신규 방문자에게 상품 카드에 별점과 리뷰 수를 보여주면, 목록을 본 세션 중 담기까지 가는 비율이 상대적으로 10% 이상 오를 것이다. |
| 근거 | 상품을 판단할 평가 정보가 카드에 없다(사용자 관점에서 나온 가설로 데이터로 직접 확인할 수 없음). 하락구간에 목록 노출→담기가 가장 크게 떨어진 쪽은 신규 세션이다(신규 41.5% → 27.0%, 재방문 50.5% → 42.5%, [docs/09 4절 "방문→담기 안에서 ②에 대해 확인한 것"](09_problem_redefinition.md)). 상세 페이지까지 본 세션의 장바구니 담기 비율이 훨씬 높다(12/1~1/11 기준 41,157세션 중 5,647개 13.7% vs 121,646세션 중 4,115개 3.4%, 담기 세션 9,762개의 약 58%가 상세 페이지를 거침, [docs/09 1절](09_problem_redefinition.md#퍼널-정의)). 단 상세 페이지를 보는 사용자가 원래 구매 의도가 높을 수 있어 인과로 읽지 않는다. |
| 주 지표 | 목록→담기 비율 |
| 위험 | 부정 리뷰 노출 시 담기 감소, 리뷰가 쌓이기까지 시간 필요 |
| 실험 시기 | 언제든 (리뷰 축적 후) |

## 우선순위 (ICE)

### 채점 기준

각 항목 1~5점이고, 점수 = Impact × Confidence × Ease다.

| 점수 | Impact (비즈니스 영향) | Confidence (성공 확신의 근거) | Ease (필요 리소스, 높을수록 적음) |
|---|---|---|---|
| 5 | 하락 원인에 직접 대응 + 영향받는 사용자 많음 | 우리 데이터·화면으로 문제 확인 + 해결 효과도 외부 사례로 뒷받침 | 화면 수정 수준, 바로 실험 가능 |
| 4 | 원인에 직접 대응하지만 범위가 일부 | 우리 데이터로 문제 확인, 해결 효과는 추론 | 작은 기능 추가, 바로 실험 가능 |
| 3 | 원인과 간접 연결, 또는 평소 약점 개선 | 업계 일반론, 외부 사례만 있음 | 새 기능 개발 필요, 또는 실험 시기 제한 |
| 2 | 일부 상품·일부 사용자에만 영향 | 정황만 있음 | 큰 개발 + 실험 시기 제한 |
| 1 | 영향 미미 | 느낌, 의견 | 큰 개발 + 연 1회만 실험 가능 |

Confidence는 "성공 가능성에 대한 확신"을 그 확신의 근거(느낌 < 업계 일반론 < 우리 데이터 < 실험 결과)로 판단했다. Ease의 리소스에는 개발 비용과 함께 효과를 확인할 수 있을 때까지의 시간도 포함했다.

## A/B 테스트 대상 선정

선정 기준:

1. 원인과의 연결
2. 실험 가능 시기
3. 실험 기간 내 표본 충분성

### 선정 결과와 근거

**선정: A3. 이탈 리마인드(메인 수단: 리타게팅 광고).** 후속 실험으로 B2(별점·리뷰)를 함께 제안한다.

| 가설 | 원인과의 연결 | 실험 가능 시기 | 표본 충분성 |
|---|---|---|---|
| A1 기프트카드 | 원인에 직접 대응 | 연말(배송 마감 이후)만 | 마감 이후 3주(24일) 안에는 상대 30% 효과만 확인 가능 |
| A2 즉시 할인 | 원인에 직접 대응 | 연말(배송 마감 이후)만 | 마감 이후 3주(24일) 안에는 상대 30% 효과만 확인 가능 |
| **A3 이탈 리마인드** | H1b 검증에서 출발(가설은 기각됐지만 이탈자가 스스로 돌아오지 않는 현상은 확인) | 상시 | 대상 수는 충분하나 리마인드 도달률에 따라 기간이 늘어남 |
| B1 품절 안내 | 원인과 별개 | 상시 | 이 데이터 기준 대상이 적어 상대 10% 효과 확인에 139~255일(약 4.5~8.5개월). 품절 상품을 구매 기록으로 추정했기 때문에 실제 재고 데이터로는 대상 규모가 다를 수 있음 |
| B2 별점·리뷰 | 원인과 별개 | 상시(리뷰가 쌓인 뒤) | 1~2주면 확인 가능(상대 10% 효과는 회복기 값 기준 약 4주) |

**선정 이유.** 세 기준을 모두 어느 정도 만족하는 가설이 A3다. A1·A2는 원인에 직접 대응하지만 1년에 한 번뿐인 시즌에만 실험할 수 있고 3주 안에는 큰 효과만 확인할 수 있다. B1·B2는 상시 실험이 가능하지만 하락 원인과는 별개다. A3는 하락구간에 이탈자가 돌아오지 않는 문제(H1b)에서 출발했고 상시 실험이 가능하며 대상 수도 충분하다.

또 A3는 연말에 **리마인드를 바로 보낼 때와 1월 중순에 보낼 때를 비교**하면, 원인 분석의 결론(연휴 중에는 담기 의도가 사라졌다가 회복기에 돌아온다)을 실험으로 검증할 수 있다. 연휴 중 리마인드로 돌아온 사용자는 담지 않고 회복기의 리마인드로 돌아온 사용자는 담는다면 이 결론이 지지된다. 다만 아래 표본 크기는 리마인드를 보낸 군과 보내지 않은 군을 비교하는 2군 기준이다. 보내는 시기까지 비교하는 설계는 군이 늘어 표본이 더 필요하고, docs/12에서 다시 계산한다.

**당시 광고 운영과 설계의 유효성.** 당시 리타게팅 광고를 운영했는지는 데이터로 확인할 수 없다(google/cpc 유입은 있으나 리타게팅 여부는 구분할 수 없다, `sql/233`). 그러나 홀드아웃 설계에서는 기존 운영이 두 그룹에 똑같이 작용하므로(같은 비율로 노출된다고 가정), 기존 운영과 무관하게 추가한 리마인드의 효과를 측정할 수 있어 설계는 유효하다. 이미 운영 중이었다면 추가 효과가 작게 나올 수 있어 더 긴 기간이 필요할 수 있다. 실제 도입 전에는 운영 중인 광고를 먼저 확인한다.

**A1은 전제가 약해졌다.** 마감 이후 기프트카드 페이지 방문 비율이 줄어(목록 방문자 대비 0.25% → 0.07%, 숫자가 작아 방향만 확인 가능) 마감 이후 기프트카드에 대한 관심이 늘었다는 전제가 뒷받침되지 않는다.

**후속 실험: B2.** 원인과는 별개지만 평소 약점을 개선하는 가설 중 가장 빨리 확인할 수 있고 표본도 충분하다(사용자 단위 필요 일수 기준선 8~16일, 회복기 10~29일). 당시 목록 카드에 별점·리뷰가 보이지 않는다는 것은 웹 아카이브 스냅샷으로 확인할 수 있다(`reports/evidence/`의 New 목록 화면, 보이는 카드 영역에는 사진·이름·가격만 있다). 다만 리뷰가 먼저 쌓여야 실험을 시작할 수 있다. 원인 분석 결과에서 **리뷰 효과는 의류에서, 그리고 신규 방문자에게서 더 클 것**이라는 예측을 세울 수 있다. 하락구간에 목록 노출→담기가 사이즈 있는 의류에서 더 크게 줄었고(Hats 제외 −44% vs 사이즈 없는 상품 −19%), 신규 세션에서 더 크게 줄었기(41.5% → 27.0%, 재방문 50.5% → 42.5%) 때문이다. 이는 예측이고 데이터로 확인한 것은 아니다.

### 표본 크기 요약

**계산 조건**: 유의수준 0.05(양측), 검정력 0.8, A/B 50:50 분할, 두 비율 비교(정규 근사). 무작위 배정 단위는 사용자다. 같은 사람이 세션마다 다른 안을 보면 효과가 섞이고, 기프트카드·할인·리마인드는 사용자에게 일관되게 노출되어야 하기 때문이다. 최소 감지 효과(MDE)는 기준값 대비 상대 10%, 20%, 30%다. 기준값과 하루 대상 수는 2020년 데이터에서 계산했다(`sql/229`~`232`, `notebooks/ab_sample_size.py`).

**한계**
- `user_pseudo_id`는 쿠키 기준이라 기기나 브라우저를 바꾸면 다른 사용자로 잡힌다. 한 사람이 두 군에 들어갈 수 있다.

- A1·A2의 기준값은 24일 전체 기준 사용자 단위 값이다. 실험이 17~18일에 끝나면 후반 진입자의 관찰 기간이 짧아져 실제 기준값은 조금 낮고 필요 표본은 더 커진다.
- 상시 가설의 진입 수는 기간 시작 때 쌓여 있던 재방문 사용자가 먼저 들어오고 이후 줄어드는 구조라, 일평균보다 끝 5일 평균이 낮다.
- A3는 대상자 전원에게 닿는다는 가정이다. 광고 노출·도달 정보가 데이터에 없어 광고가 실제로 닿는 비율은 알 수 없고, 닿는 비율이 s이면 필요 일수는 대략 1/s배가 된다.
- B1 대상 정의: docs/10 H2의 품절 추정 상품 37개(마지막 구매일 이전 28일 구매 10개 이상, 마지막 구매 1/17 이전, 마지막 구매일 + 7일부터 품절)가 목록 노출(view_item 아이템 6개 이상)에 포함된 사용자다. 재고 데이터가 없어 사이즈 품절은 빠지고 구매 패턴과 7일 가정에 의존한다. 노출은 목록 단위라 그 카드를 봤는지는 알 수 없고, 기준값(약 14%)은 목록을 많이 보는 사용자 집단이라 전체 구매전환율보다 훨씬 높다. Hats 목록만 보면 회복기 진입이 거의 없어(끝 5일 평균 6명) 1/19 view_item 기록 변화의 영향일 수 있다.
- B2는 사용자 단위로 배정하고 세션 단위 목록 도달 후 장바구니 담기 비율로 분석할 때의 설계 효과(약 1.26~1.28)를 부록에 따로 적었다.
