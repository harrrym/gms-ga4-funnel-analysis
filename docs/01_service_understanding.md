# 서비스 및 데이터 이해

## 어떤 서비스의 데이터인가

**Google Merchandise Store**는 Google 브랜드 상품(의류, 액세서리, 문구류 등)을 판매하는 실제 운영 중인 온라인 쇼핑몰이다. 일반 소비자를 대상으로 한 B2C 이커머스 사이트로, 상품 조회 → 장바구니 담기 → 결제라는 전형적인 이커머스 구매 퍼널을 가진다.

## 데이터는 무엇인가

이 사이트는 Google 애널리틱스 4(GA4)의 **표준 전자상거래 이벤트**(상품 조회, 장바구니 추가, 결제 시작, 구매 완료 등)에 더해 **향상된 측정(Enhanced Measurement)** 기능을 사용한다. 향상된 측정은 스크롤, 사이트 내 검색, 아웃바운드 링크 클릭, 동영상 조회, 파일 다운로드 등 추가 사용자 행동을 별도 코드 작업 없이 자동으로 수집하는 GA4 기능이다.

분석에 사용하는 데이터셋은 `ga4_obfuscated_sample_ecommerce`로, GA4의 **BigQuery 이벤트 내보내기(Event Export)** 형식을 그대로 따른다. 즉 실제 서비스에서 GA4 → BigQuery로 데이터를 연동했을 때 나오는 것과 동일한 스키마(중첩·반복 구조의 `event_params`, `items`, `user_properties` 등)를 가진 데이터다.

- **기간**: 2020년 11월 1일 ~ 2021년 1월 31일 (3개월)
- **난독화(obfuscated)**: 개인식별정보를 제거·해시 처리한 샘플 데이터. `user_pseudo_id` 등은 실제 사용자를 특정할 수 없다.
- **제공처**: BigQuery 공개 데이터 세트 프로그램을 통해 Google이 공식 제공하는 샘플 데이터셋

## 분석 시 유의사항

분석 기간(2020-11-01 ~ 2021-01-31)에는 **블랙프라이데이·사이버먼데이·연말연시 쇼핑 시즌**이 포함되어 있다. 이 기간의 트래픽·전환율은 평상시보다 급증하거나 프로모션의 영향을 받았을 가능성이 있으므로, 지표를 해석할 때 "이례적으로 높은/낮은 값이 시즌 효과 때문은 아닌지"를 함께 살펴봐야 한다.

## 이 프로젝트에서의 활용 방식

BigQuery 콘솔에서 직접 SQL을 실행해 필요한 지표를 추출하고, 결과를 CSV로 내려받아 로컬 Python(pandas) 환경에서 이어서 통계 검정·시각화를 진행한다.
