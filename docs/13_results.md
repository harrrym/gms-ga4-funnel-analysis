# 13. 프로젝트 결과

> 연말 구매전환율 60% 하락의 핵심은 "목록까지 와서 장바구니에 담지 않은 것"이었고, 원인은 선물 시즌 종료로 인한 구매 의도 감소로 좁혀짐. 이탈 사용자를 다시 불러오는 리마인드 실험을 설계함.

---

## 1. 분석 결과: 구매전환율 하락과 핵심 병목

### 1.1 구매전환율 하락 규모와 주요 병목

- **구매전환율(구매 세션 / 전체 세션):** 12월 초(12/1~12/13) 1.895% → 하락구간(12/19~1/11) 0.748% (**−60.5%**)
- **퍼널별 기여도:** 하락의 약 76%가 "방문 → 장바구니 담기" 단계에서 발생함. 목록 도달은 유지됐으나(지수 106) 목록 이후 장바구니 담기가 하락함(지수 47, 12월 초 = 100)
- **비즈니스 임팩트:** 놓친 구매 세션 약 945개, 매출 환산 약 $63k (이익이 아닌 매출 규모이며, 연말 성수기 기준선이라 계절적 감소가 포함된 상한)
- **데이터 보정:** 11월은 장바구니 담기·결제 시작 기록이 불완전해 기준선을 12/1~12/13으로 조정함 (구매전환율 자체에는 영향 없음)

### 1.2 원인 가설 검토

| 가설 | 판정 | 한 줄 근거 |
|---|---|---|
| **H1a 기준선 이상치** | **부분 지지** | 11월 구매전환율 1.285%는 기준선(1.895%)보다 회복기(1.142%)에 가까움. 하락의 약 1/3은 기준선이 연말 정점이었기 때문 |
| **H1b 마감 후 구매 유예** | **기각** | 7일 안 재방문율 19.8% → 12.9%, 재방문 후 장바구니 담기 비율 2.31% → 0.86%로, 미룬 것이 아니라 돌아오는 비율이 줄었음 |
| **H2 공급 감소** | **보류** | 품절 추정 비중은 늘었으나 카테고리별 하락과 상관관계가 없고, 사이즈 없는 상품도 19% 하락 |
| **H3 노출 구성 변화** | **기각** | 가격·세일·신상품 비중 변화와 카테고리별 하락 간 상관관계 없음 |
| **H4a 화면·기능 변화** | **기각** | 웹 아카이브 검토 결과 화면 구조, 장바구니 담기 버튼, 상품 카드에 변화 없음 |
| **H4b 측정 변화** | **기각** | 대체 기록(page_view, quantity>0)으로 재계산해도 방문 → 장바구니 담기 하락 패턴은 동일함 |

- **남은 설명:** 연말 선물 시즌 정점 이후 배송 마감(12/18)과 연휴를 지나며 목록 방문은 유지됐으나 구매 의도가 감소했고, 특히 선물 성격이 강한 의류에서 하락폭이 컸음
- **핵심 근거:**
  - 배송 마감과 하락 시점의 일치: 목록 이후 장바구니 담기 비율의 변화점이 12/19·12/24로 배송 마감(12/18) 전후임 (page_view 기준)
  - 기기·브라우저와 무관하게 같은 시기에 하락함
  - 사이즈 있는 의류의 하락폭이 더 큼: Hats를 제외해도 −44%로, 사이즈 없는 상품(−19%)의 2배 이상
  - 빠른 배송 선택 비율의 단계적 감소(정황): 12/13 일별 최고 21.2% → 12/24 이후 3.1%
- **한계:** 다른 가설을 배제하고 남은 설명이며 직접 검증하지 못함 → 후속 실험의 검증 대상

## 2. 해결안: 이탈 사용자 대상 리타게팅 광고

### 2.1 해결안 선정 근거

| 가설 | ICE 점수 |
|---|---|
| **A3. 이탈 리마인드** | 27 |
| **B2. 별점·리뷰** | 27 |
| **A2. 즉시 할인** | 24 |
| **B1. 품절 안내** | 24 |
| **A1. 기프트카드** | 18 |

- **선정 이유:** 문제가 집중된 퍼널 구간(목록을 보고 장바구니에 담지 않고 떠난 사용자)을 직접 타겟팅해 실험할 수 있고, 그 구간의 지표(7일 안 재방문율)를 직접 재므로 효과를 뚜렷하게 확인할 수 있음. 원인 검증에서 확인한 "떠난 사용자가 돌아오는 비율이 줄었음"과 바로 이어지며, 연말에만 실험할 수 있는 A1·A2와 달리 평소 기간에 약 17일이면 실험할 수 있음

### 2.2 A/B 테스트 설계 요약

과거 데이터로 실행할 수 없어 설계만 함.

> - **대상:** 목록을 보고 장바구니에 담지 않고 떠난 사용자
> - **자극:** 대조군(A)은 현재 운영 유지(홀드아웃), 실험군(B)은 현재 운영 + 최근 본 상품 리마인드 광고
> - **1차 지표:** 7일 안 재방문율 **15.9% → 17.5%** (상대 +10%)
> - **성공 기준:** 대조군 대비 상대 +10% 이상, p < 0.05 (양측 검정)
> - **시기:** 연말 시즌(12월 중순~1월 초)을 제외한 평소 기간
> - **기간:** **약 17일** (회복기 기준, 7일 후속 관찰 기간 포함)

- **기대 효과:** 목표 효과 달성 시 하루 추가 재방문 사용자 약 27.7명 (광고 도달률을 반영하지 않은 상한)

## 3. 한계와 배운 점

### 3.1 분석 및 검증의 한계

- 단일 시즌 데이터(11/1~1/31)라 계절 패턴으로 일반화하기 어려움
- 재고·광고비 데이터가 없어 품절은 구매 패턴으로 추정했고 광고 효율은 계산할 수 없음
- 원인은 다른 가설을 배제하고 남은 설명이며 직접 검증하지 못함
- 실험은 설계만 하고 실행하지 않아 2.2의 효과는 목표 효과를 가정한 계산이며 실제 결과가 아님

### 3.2 배운 점

1. **데이터 품질 검증의 중요성:** 11월은 장바구니 담기·결제 시작 기록이 불완전했고, 장바구니 담기 이벤트에는 실제 담은 상품이 아닌 목록 전체가 기록돼 있어 그대로 쓰면 단계별 비교가 왜곡될 수 있었음. 분석 방법만큼 데이터 품질이 중요하다는 것을 깨달았고, 이상한 숫자는 결론 전에 기록 방식부터 의심하게 됨. 이를 바탕으로 목록 노출과 상세 조회 이벤트 분리, 장바구니 담기에 실제 담은 상품과 사이즈 기록 등 측정 개선을 제안함
2. **퍼널의 곱셈 구조와 기여도 분석:** 단계별 %p 하락폭만 보고 장바구니 담기 → 결제 시작이 핵심이라 생각했지만, 구매전환율은 단계별 전환율의 곱이라 비율로 다시 분해하니 방문 → 장바구니 담기(×0.49)의 하락이 장바구니 담기 → 결제 시작(×0.71)보다 컸음. 같은 데이터도 기준을 바꿔 보면 결론이 달라진다는 것을 배움
3. **세그먼트 분할을 통한 착시 확인:** 결제 시작 → 구매 지수가 개선된 것처럼 보였지만(113, 119) 품절 모자 세션이 만든 착시였고, 이를 빼면 오히려 하락함(88, 95). 품절도 눈에 띄는 현상이었으나 사이즈 없는 상품도 19% 하락해 주원인은 아닐 정황이 있었음(H2 보류). 전체 숫자 하나로 판단하지 않고 세그먼트로 나눠 확인해야 함을 배움
4. **기각된 가설의 가치:** 사용자가 구매를 미뤘다고 가정했지만 확인해 보니 미룬 것이 아니라 돌아오는 비율이 줄었음(7일 안 재방문율 19.8% → 12.9%). 가설이 기각된 덕분에 이탈 사용자의 재방문 유도라는 해결안의 대상을 정할 수 있었음
5. **AI 도구 활용 시의 직접 검증:** AI(Claude Code)로 SQL 작성과 재계산을 빠르게 반복해 가설을 여러 번 검증할 수 있었지만, 숫자와 해석은 직접 대조해야 했음. 문서 간 숫자 불일치, 잘못된 기준선, 근거 없는 수치를 여러 번 직접 찾아 바로잡음
