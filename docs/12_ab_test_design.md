# [A/B 테스트 설계] 이탈 사용자 대상 리타게팅 광고를 통한 재방문율 개선 실험

본 설계는 데이터 분석 직후 시점을 가정하고 작성했다.

> - **대상:** 목록을 보고 장바구니에 담지 않고 떠난 사용자
> - **자극:** 대조군 A는 현재 운영 그대로(홀드아웃), 실험군 B는 현재 운영 + 최근 본 상품 리마인드 광고
> - **1차 지표:** 7일 안 재방문율 **15.9% → 17.5%** (상대 +10%)
> - **성공 기준:** 대조군 대비 상대 +10% 이상, p < 0.05 (양측)
> - **시기:** 연말 시즌(12월 중순~1월 초)을 제외한 평소 기간
> - **기간:** **약 17일** (회복기 기준, 7일 후속 관찰 포함)

---

## 1. 실험 목적

### 1.1 핵심 목적

- 목록을 보고 장바구니에 담지 않고 떠난 사용자(이탈 사용자)를 다시 불러와 7일 안 재방문율(이탈 후 7일 안에 다시 방문한 사용자의 비율)을 높이고, 돌아온 사용자가 장바구니 담기까지 이어지는지 확인

### 1.2 단계별 로드맵

- **Phase 1 (본 실험):** 리타게팅 광고의 추가 효과 검증
- **Phase 2 (후속 실험):** 리마인드 시점(이탈 직후 vs 1/12 이후) 비교로, 배송 마감과 연휴 동안 사라진 구매 의도가 1월 중순에 돌아온다는 원인 해석 검증

## 2. 문제의식 및 배경

### 2.1 문제 규모

- 구매전환율: 12월 초 1.895% → 하락구간(12/19~1/11) 0.748% (**−60.5%**)

![구매전환율, 12/19부터 급락](../reports/charts_ver2/problem_omtm_daily.png)

### 2.2 퍼널 병목

구매전환율 하락을 퍼널 단계별로 나눠보니 하락의 약 76%가 "방문→장바구니 담기" 단계에서 발생했다.  
그 안에서도 상품 목록까지 오는 비율은 유지됐고, 목록을 본 뒤 장바구니에 담는 비율이 떨어졌다.  
그래서 목록을 보고 담지 않고 떠난 사용자를 실험 대상으로 삼는다.

| 지표 (12월 초 = 100, page_view 기준) | 하락구간 | 회복기 |
|---|---|---|
| 목록 도달 지수 | 106 | 101 |
| 목록 도달 후 장바구니 담기 지수 | 47 | 56 |

- 목록 도달은 유지, 장바구니 담기 비율은 하락하고 회복기에도 12월 초의 절반 수준
- 하락 시점: 배송 마감(12/18) 전후, 변화점 12/19·12/24

![목록→장바구니 담기 비율, 배송 마감 전후 계단식 하락](../reports/charts_ver2/cause_stage2_daily_steps.png)

### 2.3 이탈 사용자 행동

- 대상: 목록을 보고 장바구니에 담지 않고 떠난 사용자 (7일 추적)

| 지표 | 기준선 | 하락구간 | 회복기 |
|---|---|---|---|
| 7일 안 재방문율 (1차 지표) | 19.8% | 12.9% | 15.9% |
| 재방문한 사용자 중 장바구니에 담은 비율 | 11.7% | 6.6% | 9.4% |
| 7일 안 재방문 후 장바구니 담기 비율 (2차 지표) | 2.31% | 0.86% | 1.51% |

- 회복기는 7일 추적이 가능한 1/12~1/24 세션 기준
- 해석: 이탈 사용자가 스스로 돌아오는 비율과 돌아와서 담는 비율이 모두 하락했고, 회복기에는 하락구간보다 회복했지만 연말 정점이었던 12월 초보다는 낮음

![이탈 사용자, 재방문도 재방문 후 담기도 줄었다](../reports/charts_ver2/cause_h1b_return_cart.png)

### 2.4 원인 해석 및 한계

- 남은 설명: 배송 마감 이후 연휴를 지나며 장바구니에 담으려는 의도 감소
- 한계: 다른 가설을 배제하고 남은 설명이며 직접 검증하지 않음 → 후속 실험의 검증 대상

![12/19 목록 화면: 배송 마감 배너](../reports/evidence/2020-12-19_new-banner-holiday-delivery.png)

*웹 아카이브 캡처일 기준이며, 게시 시작 시점은 알 수 없음*

#### 왜 평소 기간에 먼저 실험하는가

- 연말 하락의 원인: 목록을 보고 떠난 사용자가 스스로 돌아오지 않음 (7일 안 재방문율 19.8% → 12.9%)
- 회복기에도 이 비율은 15.9%에 그침 → 연말만의 문제가 아니라 평소에도 있던 약점이 연말에 더 크게 드러난 것으로 볼 수 있음
- **Phase 1:** 이 약점을 다루는 리마인드의 효과를 시즌 영향이 없는 평소 기간에 먼저 검증
- **Phase 2:** 효과가 확인되면 연말에 언제 보내야 하는지를 검증

## 3. 가설 및 가정

### 3.1 핵심 가설 (H1)

**H1: 목록을 보고 장바구니에 담지 않고 떠난 사용자에게 리타게팅 광고를 보여주면, 7일 안 재방문율이 15.9%에서 17.5%(상대 +10%) 이상으로 오를 것이다.**

- **기준값:** 15.9% (회복기 값)
  - 이유: 12월 초는 연말 정점이고 평소는 회복기에 가까움
- **최소 감지 효과:** 상대 +10%
  - 외부 연구: 의류·스포츠용품 온라인 소매업체가 상품 페이지 방문자에게 리타게팅 광고를 보여준 실험에서 광고가 웹사이트 방문을 17%, 구매를 11% 늘렸음(Johnson, Lewis, Nubbemeyer, 2017, Journal of Marketing Research)
  - 보수적으로 정한 이유: 이 수치는 광고를 실제로 본 사용자 기준이고, 우리 실험은 배정된 전원 기준이라 광고가 일부에게만 닿으면 전체 효과가 작아짐. 그래서 17%보다 보수적인 10%를 설계 기준으로 정함
  - 사용자 수 기준 비교: 방문한 사용자 수 기준으로는 +26.6%로, 우리 지표와 더 가까운 이 수치에 비해서도 10%는 보수적인 기준
  - 의미: 효과 예측이 아니라 확인 가능한 최소 크기임
- **반증 조건:** 대조군(A) 대비 상대 +10% 미만이거나 차이가 유의하지 않으면 가설 기각 (p ≥ 0.05, 양측)
- **기대 효과:** 목표 효과 달성 시 하루 추가 재방문 사용자 약 27.7명, 그중 장바구니에 담는 사용자 약 2.6명. 회복기 기준이며 재방문한 사용자 중 장바구니에 담은 비율 9.4%를 적용했고, 광고 도달률을 반영하지 않은 상한
- **원인 해석 검증 가치:** 이 실험의 가치는 효과 크기뿐 아니라, 후속 실험을 통해 원인 해석을 검증하는 데에도 있음

### 3.2 확인할 가정

- **가정 1:** 이탈 사용자는 상품에 대한 관심은 남아 있지만 다시 방문할 계기가 없어 돌아오지 않으며, 광고로 계기를 주면 다시 방문해 장바구니에 담을 것이다.
  - 왜 확인이 필요한가: 회복기에도 7일 안 재방문율이 15.9%에 그쳐 스스로 돌아오는 비율이 낮지만, 관심이 없어서인지 계기가 없어서인지는 확인하지 못함. 관심 자체가 사라졌다면 리마인드는 효과가 없음
- **가정 2:** 리타게팅 광고는 이 사용자들에게 닿는 효과적인 채널일 것이다.
  - 왜 확인이 필요한가: 도달률을 알 수 없음

## 4. 실험 계획

### 4.1 실험 설계

#### 개요

| 항목 | 내용 |
|---|---|
| 실험 대상 | 목록을 보고 장바구니에 담지 않고 떠난 사용자 |
| 그룹 배정 | 사용자 단위(`user_pseudo_id`) 무작위 50:50 |
| 표본 규모 | 그룹당 **8,605명** (회복기 기준, 상대 +10%) |
| 실험 시기 | 연말 시즌(12월 중순~1월 초)을 제외한 평소 기간 |
| 실험 기간 | **약 17일** (회복기 기준, 7일 후속 관찰 포함). 광고 도달률이 s이면 약 1/s배 |
| 실험 자극 (대조군 A) | 현재 운영 그대로(홀드아웃) |
| 실험 자극 (실험군 B) | 현재 운영 + 최근 본 상품 리마인드 광고 |
| 광고 메시지 | 최근 본 상품을 다시 보여주는 일반 리마인드. 배송·시즌 메시지 아님 |

- 실험 시기 이유: 연말에는 구매 결정이 길어져(하락구간 의류·가방 등에서 결제까지 7일 넘게 걸린 비율 7.02%, 평소 약 3%) 7일 기준 지표가 맞지 않고, 시즌 효과도 섞이기 때문
- 기준선 기준 표본과 기간, 상대 5%·15% 효과 기준은 부록 A

#### 지표

| 항목 | 내용 |
|---|---|
| 1차 성공 지표 | 7일 안 재방문율 |
| 2차 지표 | 7일 안 재방문 후 장바구니 담기 비율: 돌아온 사용자가 실제로 담는지 확인. 표본이 부족해 유의성 판단이 아니라 방향 확인용 |
| 측정 방법 | GA4 BigQuery 내보내기(사용자 ID 기준)와 광고 플랫폼의 홀드아웃 배정·노출 데이터 |
| 새로 수집할 데이터 | 사용자별 배정 그룹과 광고 노출 여부를 GA4 데이터와 연결 (현재 데이터에는 없음) |
| 가드레일 지표 (구매 전환) | 장바구니에 담은 사용자의 구매율: 담기만 늘고 구매는 늘지 않는지 확인 |
| 가드레일 지표 (담기 비율) | 재방문한 사용자 중 장바구니에 담은 비율: 광고로 의도가 낮은 방문만 늘어 비율이 떨어지지 않는지 확인 |
| 가드레일 지표 (광고 효율) | 광고비 대비 매출: 광고 효율 확인 |
| 모니터링 지표 | 7일 안 구매율, 광고 노출 빈도 |

- 7일 기준: 구매 관련 결정은 대부분 일주일 안에 이뤄지는 편임(장바구니 담기 후 결제 시작까지 7일 넘게 걸린 비율은 평소 약 3%). 이 실험의 지표가 아니라 다른 단계의 수치를 참고한 근거임. 7일이면 요일이 한 바퀴 돌아 요일별 차이가 섞이지 않음
- 2차 지표를 방향 확인용으로 두는 이유: 재방문 후 장바구니 담기 비율은 기준값이 낮아(회복기 1.51%) 상대 +10% 확인에 약 135일이 필요함(docs/11 부록)
- 광고비 기준값: 도입 시점 광고 계정 값으로 설정. 이 데이터에는 광고비가 없음

#### 의사결정

| 항목 | 내용 |
|---|---|
| 성공 기준 | 대조군(A) 대비 상대 +10% 이상이고 p < 0.05 (양측 z-검정) |
| 애매 기준 | 상대 +10% 이상이나 p ≥ 0.05, 또는 +10% 미만이나 p < 0.05 (B가 A보다 높은 경우) |
| 실패 기준 | 위 두 경우가 아닌 나머지 |
| 성공 시 | 상시 도입 후 Phase 2 진행 |
| 실패 시 | Phase 2 미진행. 사이트 안 메시지 검토(재방문한 사용자의 장바구니 담기를 직접 도움) |
| 결과가 애매할 때 | 미리 정한 기간 유지 |
| 기간 연장 판단 | 결과를 보기 전에 정한 기준(예: 최소 표본 미달)으로만 판단 |

- 배정 점검: 실험 시작 후 두 그룹 인원 비율을 먼저 점검(배정 오류 확인)
- 중간 결과 확인 금지: 정한 기간이 끝나기 전에는 결과를 보고 멈추지 않음

### 4.2 리스크 및 한계

- 당시 리타게팅 광고 운영 여부를 알 수 없음. 홀드아웃 설계라 기존 광고가 두 그룹에 같은 비율로 노출되면 추가 효과는 측정 가능하나, 이미 운영 중이었다면 효과가 작게 나와 기간이 늘 수 있음. 도입 전 광고 계정에서 확인
- 광고 도달률을 알 수 없고, 광고 차단·쿠키 삭제·여러 기기 사용으로 도달이 제한됨
- 사용자 ID는 쿠키 기준이라 기기를 바꾸면 다른 사용자로 집계
- 광고 효과 측정은 광고 플랫폼의 홀드아웃 방식에 의존
- 리마인드는 재방문을 주로 해결하고, 재방문한 사용자의 장바구니 담기는 사이트 안 메시지가 더 직접적일 수 있음

## 6. 후속 가설 및 확장 아이디어

**로드맵:** Phase 1 → Phase 2

### 6.1 Phase 2 후속 실험 (리마인드 시점 비교)

- **가설:** 배송 마감 이후 이탈한 사용자에게 1월 중순(1/12부터) 광고를 보여주면, 이탈 직후에 보여준 경우보다 1/31까지 재방문 후 장바구니 담기 비율이 상대 30% 이상 높을 것이다.
  - +30%의 이유: 배송 마감 이후 약 3주 안에 확인 가능한 최소 효과
- **의미:** 연말 하락에 대한 원인 해석을 실험으로 검증
- **관련 가정**
  - 목록을 보고 떠난 사용자가 장바구니에 담지 않은 주된 이유는 선물 시즌이 끝나 구매 의도가 사라졌기 때문일 것이다.
    - 왜 확인이 필요한가: 원인 분석에서 다른 가설을 배제하고 남은 설명이라 직접 확인하지 못함
  - 1월 중순(1/12부터)에는 사용자 스스로의 구매 동기가 돌아올 것이다.
    - 한계: 회복기 수치로 추정했을 뿐 개인 단위로 확인하지 않음
- **메시지:** 두 그룹 동일하게 "나를 위한 구매"(예: 새해 맞이) + 최근 본 상품, 시점만 다르게. "늦은 선물"·배송일 메시지는 쓰지 않음
  - 이유: 마감 이후 선물 의도 감소 정황
- **광고 노출 기간:** 두 그룹 모두 광고를 7일 동안만 노출(이탈 직후 그룹은 이탈일부터 7일, 1/12 이후 그룹은 1/12부터 7일)
  - 이유: 노출 기간 길이가 다르면 시점 효과와 노출 기간 효과를 구분할 수 없기 때문
- **검토한 대안:** 1차 지표를 이탈 후 1/31까지 재방문율로 바꾸면 표본은 충분해지지만(상대 10%에 최소 도달률 47%), 1/12 이후 구매 의도가 돌아오는지를 직접 검증하지 못해 채택하지 않음
- **실현 가능성:** 한 시즌 안에 확인하려면 광고가 대상의 76% 이상에게 닿아야 해 현실적으로 어려움. 두 시즌 결과를 합치거나 첫 시즌은 방향을 보는 탐색 실험으로 운영
- **표본 계산:** [부록 B](#부록-b-phase-2-표본-계산)
  - 한계: 노출 기간을 7일로 맞추면 기준값과 표본 계산이 달라질 수 있음. 부록 B는 노출 기간을 맞추기 전 계산이며 재계산하지 않음

## 부록 B. Phase 2 표본 계산

- 기준값 1.32%는 이탈 후 1/31까지의 값이며, 7일 값(0.86%)과 다름
- 설계: 2그룹(이탈 직후 vs 1/12 이후), 조건은 부록 A와 같음(`sql/244`)
- 기준값 산출
  - 하락구간(12/19~1/11)에 목록을 보고 장바구니에 담지 않고 떠난 사용자 39,423명 중 이탈 후 1/31까지 재방문해서 담은 사용자 520명
  - 광고 없던 2020년 자연 값, 재방문 사용자 5,906명(15.0%)

| 최소 감지 효과(상대) | 그룹당 필요 수 | 전체 필요 수 | 마감 이후 대상 (12/19~1/11) | 24일 안에 모을 수 있나 | 필요한 최소 도달률 |
|---|---|---|---|---|---|
| 10% | 123,229 | 246,458 | 39,423명 | 불가 (약 146일*) | 625% (불가) |
| 20% | 32,252 | 64,504 | 39,423명 | 불가 (약 39일*) | 164% (불가) |
| **30%** | **14,976** | **29,952** | **39,423명** | **가능 (약 19일)** | **76%** |

- `*`: 24일 안에 도달하지 못해 기간 끝 5일 평균 진입 수로 외삽한 값
- 필요한 최소 도달률: 전체 필요 수 ÷ 대상 39,423명. 광고가 닿는 대상이 이 비율 이상이어야 마감 이후 기간 안에 확인 가능

**읽는 법과 한계**
- 마감 이후 기간 안에 확인 가능한 효과는 상대 30%뿐, 10~20% 효과는 한 시즌으로 확인 불가
- 기준값은 광고가 없던 때의 값, 두 그룹 모두 광고를 보므로 실제 기준값은 더 높을 수 있고 필요 표본도 달라짐
- 이탈일에 따라 관찰 기간이 다름(12/19 이탈 43일, 1/11 이탈 20일), 두 그룹을 같은 날(1/31)까지 비교해 맞춤
- 1월 중순(1/12부터)에 광고를 보는 그룹은 이탈이 1/11 근처인 사용자와 이탈 직후 그룹의 시점 차이가 거의 없음
- 이탈일별 기준값: 12/19~12/23 이탈자 1.88%, 12/24~1/3 이탈자 0.90%, 1/4~1/11 이탈자 1.44%
  - 연휴 기간 이탈자가 가장 낮고 그 뒤 이탈자는 더 높음 → Phase 2 가설과 방향은 같으나 광고 효과를 본 것은 아님
